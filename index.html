06 — IoT

IoT Integration Detail

การเชื่อมต่อ Hardware กับ Software ผ่าน MQTT Protocol

⚡
ESP32 Firmware Logic
// ESP32 Arduino Code (Simplified) #include <WiFi.h> #include <PubSubClient.h> #include <DHT.h> const char* DEVICE_ID = "ESP32-ROOM-A"; const char* MQTT_TOPIC_SENSOR = "office/room-a/sensor"; const char* MQTT_TOPIC_CMD = "office/room-a/command"; void publishSensorData() { float temp = dht.readTemperature(); bool occ = digitalRead(PIR_PIN); // ส่ง JSON ไปยัง MQTT Broker String payload = "{\"temp\":" + String(temp) + ",\"occupancy\":" + String(occ) + ",\"device\":\"" + DEVICE_ID + "\"}"; client.publish(MQTT_TOPIC_SENSOR, payload.c_str()); } // รับคำสั่งจาก Server (เปิด/ปิดแอร์-ไฟ) void onMessage(String topic, String message) { if (message == "light_on") digitalWrite(LIGHT_RELAY, HIGH); if (message == "ac_on") digitalWrite(AC_RELAY, HIGH); }
📨
MQTT Topic Structure
office/{room-id}/sensor
📤 ESP32 Publish ข้อมูล Sensor ทุก 30 วิ
office/{room-id}/command
📥 Server Publish คำสั่งไปยัง Device
office/{room-id}/status
📤 Device Report Online/Offline Heartbeat
office/{room-id}/display
📥 Server ส่งข้อมูลไปแสดงบน LED Display
🤖
Automation Rules
⏰ Pre-Meeting
ก่อนเวลาประชุม 5 นาที → เปิดแอร์ + ไฟ + อัปเดต LED Display
🚫 No-Show Cancel
PIR = 0 นาน 10 นาที หลังเวลาเริ่ม → ยกเลิกการจอง + แจ้ง Notify
🔚 Post-Meeting
ผ่านเวลาสิ้นสุด + PIR = 0 → ปิดแอร์/ไฟ + อัปเดตสถานะ completed
⚠️ Overrun Alert
PIR = 1 แต่เวลาหมดแล้ว → แจ้งเตือนผู้จองถัดไปว่าห้องยังไม่ว่าง
